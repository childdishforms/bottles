# Журнал розлива

Локальное учебное веб-приложение для учёта партий питьевой воды. После входа на одной странице доступны выпуск партии, контроль качества и приёмка на склад. Расчёт годных бутылок выполняется и на Java, и в отдельной консольной программе на Python.

## Подготовка

На этом компьютере локальная база `water` и роль `water` настроены на `127.0.0.1:5432`. Для повторного запуска из каталога проекта выполните `bash start-local.sh` и введите пароль роли при скрытом запросе. Откройте [журнал](http://127.0.0.1:18080). Для входа используйте созданную учётную запись журнала. Следующие шаги описывают установку с нуля.

Требуются Java 17 или новее, Maven и PostgreSQL. Выполняйте команды из каталога проекта. Для сборки запустите:

```sh
mvn package
```

В выделенной для проекта пустой базе выполните файл `schema.sql` через SQL-редактор или командой:

```sh
psql -X -v ON_ERROR_STOP=1 -h localhost -U ИМЯ_РОЛИ -d ИМЯ_БАЗЫ -f schema.sql
```

Схема создаётся один раз. В справочник добавляется негазированная вода в бутылках 500 и 1500 мл. Роль приложения должна иметь права на чтение и запись в созданные таблицы и последовательности.

## Подключение и вход

Задайте параметры в локальном окружении терминала или IDE. Приложение читает их при подключении.

| Переменная | Значение |
|---|---|
| WATER_DB_URL | JDBC-адрес в формате `jdbc:postgresql://localhost:5432/ИМЯ_БАЗЫ` |
| WATER_DB_USER | Роль PostgreSQL |
| WATER_DB_PASSWORD | Пароль роли PostgreSQL |

Пример для zsh на macOS. Первые два значения замените локальными. Ввод пароля скрыт.

```sh
export WATER_DB_URL='jdbc:postgresql://localhost:5432/ИМЯ_БАЗЫ'
export WATER_DB_USER='ИМЯ_РОЛИ'
read -rs 'WATER_DB_PASSWORD?Пароль PostgreSQL: '
export WATER_DB_PASSWORD
```

Создайте пользователя журнала в интерактивном терминале. Программа запросит логин и пароль, затем сохранит логин и хеш пароля с индивидуальной солью.

```sh
java -jar target/water-journal-1.0.0.jar --add-user
```

Для запуска сервера выполните:

```sh
java -jar target/water-journal-1.0.0.jar
```

Откройте [локальное приложение](http://127.0.0.1:8080). Форма входа открывается и до настройки базы. Для входа и работы с партиями требуется подключённая база с созданным пользователем.

## Демонстрация

1. Нажмите «Новая партия». Введите номер, дату, продукцию, выпуск 1000 и брак 12.
2. Раскройте «Контроль качества» в строке партии. Допустите партию. Для отклонения обязательна причина.
3. Раскройте «Приёмка на склад» и подтвердите приёмку 988 бутылок. В строке появится статус «На складе».
4. Для проверки процедурной версии выполните `python3 python/batch.py 1000 12 --decision approved`. С флагом `--received` к повторной приёмке доступны 0 бутылок.
